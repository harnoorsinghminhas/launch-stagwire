## Logo artwork

`assets/logo.svg` and `assets/favicon.svg` (one letter) are drawn from **Fraunces Bold** (SIL OFL 1.1, https://github.com/undercasetype/Fraunces). The letters were converted to outlines, so no font file is shipped.

## System fonts

The CSS lists system fonts (for example Segoe UI, Georgia or Impact) only as fallbacks. They are drawn by the visitor's own device;
this site does not ship or embed them.
